#  Fashion Haul Cara – E-Commerce Website

## 📌 Project Overview
Fashion Haul Cara is a responsive front-end e-commerce website designed to showcase fashion products and simulate a modern online shopping experience.

The project focuses on building a clean and user-friendly interface using core web technologies. It demonstrates fundamental skills in front-end development such as page layout design, responsive UI, and structured navigation.


## Features

- Modern and responsive landing page
- Product listing with featured and new arrival sections
- Product cards with pricing and ratings
- Promotional banners and discount sections
- Newsletter subscription section
- Multi-page website navigation
- Contact page for user queries
- Mobile-friendly layout


## 🖥️ Website Pages

The project includes the following pages:

- Home Page
- Shop Page
- Blog Page
- About Page
- Contact Page

Each page is connected through a navigation bar to simulate a real online shopping platform.


## Tech Stack
